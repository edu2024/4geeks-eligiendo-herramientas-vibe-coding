# Eligiendo tus Herramientas de Vibe Coding — Una Guía Práctica

> Proyecto del curso Full Stack with AI — 4Geeks Academy

## 🎯 Propósito

Seleccionar las herramientas de Vibe Coding adecuadas puede transformar tu experiencia de desarrollo. Este proyecto te guía paso a paso para evaluar, puntuar y elegir las mejores herramientas según tus necesidades específicas.

## 📋 Estructura del proyecto

| Archivo | Descripción |
|---|---|
| `README.md` | Vista general del proyecto |
| `task-1.md` | **Tarea 1** — Identificar necesidades y criterios |
| `task-2.md` | **Tarea 2** — Investigar herramientas y completar tabla de puntuación |
| `task-3.md` | **Tarea 3** — Analizar resultados y tomar decisiones |
| `task-4.md` | **Tarea 4** — Documentar tu toolkit y compartirlo |
| `scoring-table.md` | Tabla de puntuación para evaluar herramientas |

## 🧭 Cómo abordar este proyecto

1. Comienza con **Task 1** y avanza en orden secuencial.
2. Marca las casillas de verificación `[ ]` a medida que completes cada paso.
3. Usa la **tabla de puntuación** como referencia viva — actualízala conforme investigues.
4. Al finalizar, comparte tu toolkit en redes sociales (opcional).

## 🧠 Principios clave

- **¿"Vibing" o Ingeniería?** — Adapta la herramienta al tipo de proyecto.
- **Una herramienta para gobernarlas a todas (¡casi!)** — Busca profundidad con pocas herramientas clave.
- **No olvides las bibliotecas** — Las librerías estándar son alternativas potentes y rentables.
- **Ciclo de vida completo** — Considera marketing y automatización, no solo construir.
- **El toque humano es clave** — Tu intuición y pruebas son irremplazables.
