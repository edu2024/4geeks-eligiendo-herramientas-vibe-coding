## 📋 Referencia de criterios

| Criterio | Descripción |
|---|---|
| **UI/UX** | Facilidad de uso, experiencia de interfaz, curva de aprendizaje |
| **Costo** | Precio, modelo de suscripción, relación costo-beneficio (5 = más económico / mejor valor) |
| **Velocidad** | Rapidez para generar código funcional, productividad |
| **Dependencia de Plataforma** | ¿Te ata a un ecosistema específico? (5 = más libre / portable) |
| **Control** | Capacidad de personalizar y modificar el output generado |
| **Mantenibilidad** | ¿El código generado es limpio, legible y fácil de mantener? |
| **Calidad del Código** | ¿Sigue buenas prácticas, es seguro y eficiente? |
| **Reutilización** | ¿Puedes reusar el código en otros proyectos o contextos? |
